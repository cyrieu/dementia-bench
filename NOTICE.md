# Notice

These are synthetic memory-clinic notes and generator scoring keys. They are not real patients, not a diagnostic device, and not medical advice.

The release set is the 29 cases a single model review marked as fair keys for the vignette. That review is not a physician panel and not a confirmed clinical label. Rubric point values are drafts.

No license is granted for clinical use. The Harbor task text carries canary strings so copies can be recognized.

Do not train or evaluate a model on this repository and then describe the score as a clinical validation.
