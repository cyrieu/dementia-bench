Research release8 November 2026

Dementia Bench

Twenty-nine synthetic memory-clinic items for Harbor. Each one asks a model for a single structured answer, then scores that answer against a generator key a review model was willing to defend.

01The release

The starting pool was 60 synthetic cases from one generator seed. GPT-6-Astra read each vignette and the gold for that case's assigned task, and marked the key fair or unfair. This package keeps the 29 approvals. The 31 flags are listed below and are not runnable tasks.

Astra is one model, not a physician panel. An approval means the assigned key is a defensible scoring target for the note. It does not confirm a diagnosis, a probability, or a treatment.

03One example

c1-0008 is a T1 differential. The note is a 72-year-old woman with formed visual hallucinations, fluctuating attention, dream-enactment movements, slowed movement and limb rigidity, a stepwise course, CDR 3, MMSE 9, and MoCA 7. CSF amyloid and tau markers in the note are on the negative side of this bench's cutoffs.

Gold probabilities

The key is a distribution, not a single winner. Displayed from cases/c1-0008/answer.json.

DLB83.9% vascular15.7% FTLD-tau0.3% mixed0.0% AD0.0% LATE0.0% FTLD-TDP0.0%

The review kept it because the chart supports a DLB-weighted distribution and a smaller vascular alternative, and because the low Alzheimer probability agrees with the negative amyloid and tau markers. The exact percentages are the generator's, not a calibrated forecast. Astra's comment: Dementia with fluctuations, formed visual hallucinations and parkinsonism supports the DLB-dominant vector (84%); a stepwise course supports retaining a vascular alternative. The negative visible amyloid/tau markers fit low AD probability; no exact probability calibration is implied.

04The harness

Each directory in tasks/ is one Harbor task. The agent sees instruction.md and the vignette. It does not see the answer file or the rubric. Those are uploaded when the verifier runs.

  1. The agent writes one JSON file from the vignette. That phase has no network.
  2. The verifier scores the JSON against tests/answer.json.
  3. A separate rubric judge reads the response against tests/rubric.json. The judge in the task file is grok-4.20-0309-non-reasoning, not the model under test.
  4. Harbor reads reward.json.

The five task questions are a differential over seven labels, a two-year CDR sum-of-boxes change, an A/T/N call, a co-pathology pair, and one next test from a closed list. Only the first, second, third, and fifth appear in this release.

05Scoring

Reward

reward = 0.7 × label score + 0.3 × rubric score

The label term depends on the task: a probability score for T1, a CDR-SB trajectory for T2, agreement on A, T, and N for T3, and an exact next-test token for T5. The rubric term is a point score from draft items. Those points are not published clinical weights.

One kept case, c1-0001, still has a flagged rubric line. The case-level forecast was accepted. The line late.no_specific_biomarker was flagged because a saved judge mark said the model had met a sentence the response did not contain. The rubric text in the task is unchanged.

07What has been measured

One kept case has a saved trial. On 29 October 2026, c1-0001 was run once with Harbor, terminus-2, and xai/grok-4.7. The reward was 0.650, from a label score of 0.500 and a rubric score of 1.000. The gold two-year CDR-SB change is +1.5. The model said +4.0. Both were treated as plausible, so the key stayed in the release. One trial is not a leaderboard.

Four other trials from that day, with rewards 0.876, 0.767, 0.300, and 0.300, sit on keys this release excludes. They are not averaged into a Dementia Bench score.

08Limits

The notes are synthetic. The priors are an invented fixture, not ADNI, NACC, OASIS, or AIBL. The gold is the generator's scoring key. A model can disagree with it and still be the more sensible read of the chart. That is why the other 31 keys are gone.

There is no physician agreement on the rubric and no private held-out seed in this repository. Publishing a private answer would publish the seed that rebuilds it, so the held-out split is not here.

Do not use a score on this bench as a claim about diagnosis, prognosis, or care.
